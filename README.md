# MomPulse («МамаТрекер») — Telegram Mini App для беременных 🌸

Интерактивный персональный календарь-дневник для беременных со специализацией на контроле самочувствия, токсикоза, шевелений плода и экспорте медицинских отчетов для врача.

---

## 🌟 Ключевые возможности

1. **Онбординг и точный расчет гестационного срока:**
   - Ввод даты последних месячных (LMP) или предполагаемой даты родов (ПДР / EDD).
   - Точный расчет недель и дней (например: *«14 недель и 3 дня • II триместр»*).
   - Интерактивный бейдж размера плода с аналогиями фруктов/овощей (от макового зернышка до арбуза) с весом и ростом.

2. **Интерактивный календарь:**
   - Горизонтальная лента текущей недели + раскрывающийся полный месяц.
   - Индикаторные точки для заполненных дней, пропусков и текущей даты.
   - Быстрый просмотр и редактирование дневника за любой выбранный день.

3. **Ежедневный чек-ин самочувствия (Daily Diary):**
   - **Токсикоз и тошнота:** шкала 0–5 (от «Отлично» до «Рвота»).
   - **Уровень энергии:** 1–5.
   - **Симптомы:** чипсы с мультивыбором («Изжога», «Отеки», «Боль в пояснице», «Сонливость» и др.).
   - **Водный баланс:** интерактивный счетчик стаканов по 250 мл (+ / -).
   - **Шевеления плода:** счетчик толчков с тактильной отдачей (Haptic Feedback) для II–III триместров.
   - **Питание:** теги тяги к еде и текстовые заметки.
   - **Показатели:** вес (кг) и артериальное давление (верхнее / нижнее).
   - **Вопросы к врачу:** поле для фиксации мыслей и вопросов перед приемом.

4. **Аналитика и экспорт для врача:**
   - Графики динамики веса, токсикоза и энергии.
   - Генератор медицинского отчета за 14 или 30 дней в один клик с возможностью скопировать или отправить в Telegram.

5. **Telegram Mini App UX:**
   - Нежная пастельная палитра (пудровый, лавандовый, персиковый, молочный).
   - Нативная виброотдача `HapticFeedback` на каждый тап и выбор.
   - Поддержка нативной кнопки Telegram `MainButton`.
   - Защита HMAC-SHA256 для валидации строки `initData`.

## 🚀 Быстрый старт

### 1. Запуск базы данных (PostgreSQL)

В корневой папке проекта есть готовый `docker-compose.yml`:
```bash
docker compose up -d
```

### 2. Запуск Backend (FastAPI)

1. Перейдите в папку бэкенда:
   ```bash
   cd backend
   ```
2. Создайте виртуальное окружение и установите зависимости:
   ```bash
   python -m venv venv
   # Windows:
   venv\Scripts\activate
   # Linux/macOS:
   source venv/bin/activate

   pip install -r requirements.txt
   ```
3. Настройте файл `.env`:
   ```bash
   copy .env.example .env
   # Укажите ваш BOT_TOKEN от @BotFather
   ```
4. Запустите сервер:
   ```bash
   uvicorn app.main:app --reload --port 8000
   ```
   Документация Swagger будет доступна по адресу: `http://localhost:8000/docs`.

### 3. Запуск Frontend (React + Vite + Tailwind CSS)

1. Перейдите в папку фронтенда:
   ```bash
   cd frontend
   npm install
   ```
2. Запустите dev-сервер:
   ```bash
   npm run dev
   ```
   Приложение откроется по адресу: `http://localhost:5173`.

## 🔒 Безопасность и Telegram WebApp

- Бэкенд валидирует `initData` по официальной спецификации Telegram (HMAC-SHA256 с ключом `WebAppData`).
- Защита от устаревших сессий (срок действия `auth_date` не более 24 часов).
- Для локальной отладки в обычном браузере вне Telegram предусмотрен флаг `ALLOW_DEV_AUTH_BYPASS=True` и заголовок `X-Dev-User-Id`.
